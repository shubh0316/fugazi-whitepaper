# 15. Roadmap

Augle is one platform with a phased expansion plan. Every phase builds on the traction, infrastructure, and user base of the phase before it. The deliberative engine does not change — the contexts it serves expand.

## 15.1 Phase 1 — Prediction Markets (Live)

Launch. Prove the engine. Build the base.

Phase 1 is Augle's public launch in Markets mode, targeted at prediction market users on Polymarket and Kalshi. Live since April 2026. The goal is straightforward: demonstrate that structured multi-agent deliberation produces measurably better prediction accuracy than the alternatives, and build a user base that can speak to that improvement from direct experience.

Phase 1 priorities:
- Full Markets mode launch with complete seven-agent ensemble (shipped)
- Credit system live with reserve and refund logic (shipped)
- Free Standard-depth session for user acquisition (shipped)
- Session history and PDF export (shipped)
- Source Verification Service rollout (shipped in v2.0 architecture)
- Opus 4.6 Contrarian on Deep sessions (shipped in v2.0 architecture)
- Core prediction market community engagement — crypto Twitter, forecasting communities, Polymarket and Kalshi power users
- Accuracy dashboard published by day 90 — public, auditable, calibration-tracked

What success looks like: Measurable traction — active sessions, returning users, community referrals, documented accuracy improvement against resolved contracts — that validates the core deliberative value proposition before raising institutional capital.

## 15.2 Phase 2 — Letters and Science and Enterprise

Letters and Science. Expand the surface area.

With Markets mode traction established, Phase 2 introduces Letters and Science (academic and research mode) and begins the expansion into adjacent verticals: venture research, legal analysis, and enterprise strategy.

Phase 2 priorities:
- Letters and Science launch with light theme, evidence weight output framing, and academic citation handling
- Topic Architect neutrality check on free-form research questions
- Retraction database integration in the Source Verification Service
- Enterprise pricing tier for high-frequency users — alongside, not replacing, the credit model
- API access for institutional and developer integration
- Vertical-specific onboarding flows for legal, VC, and academic users
- Partnership conversations with relevant platforms and institutions
- Mistral Large enablement for enterprise and regulatory contexts

## 15.3 Phase 3 — Platform Expansion

Collaboration. Customization. Broader reach.

Phase 3 extends Augle's capabilities beyond individual sessions. The deliberative process becomes a collaborative one — teams can run sessions together, organizations can configure ensemble parameters for their specific context, and the platform develops integrations with the tools where consequential decisions are already being made.

Phase 3 priorities:
- Collaborative sessions — multiple users contributing to a single deliberation through Guardian-mediated turn-taking
- Custom agent configuration for enterprise clients (model selection, temperature ranges, ensemble subsets)
- Integrations with prediction market platforms, research tools, and professional workflows
- Expanded platform mode library — legal, venture, enterprise, regulatory
- International market expansion
- Compliance certification offering for regulated industries

## 15.4 What Does Not Change

The deliberative engine is fixed across all three phases. Seven agents. Three rounds. Guardian integrity layer. Source Verification Service. Reality-graded outputs. Audit trail. Deterministic verdict computation.

New modes, new integrations, and new user contexts are all interfaces to the same underlying process. Augle's competitive advantage is not in any one feature — it is in the structured ensemble architecture that every phase is built on.

*Phase 1 traction informs the Phase 2 raise. Phase 2 revenue funds Phase 3 build. The roadmap is designed to be self-reinforcing.*
